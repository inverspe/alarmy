# Alarmy (personal) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal iPhone alarm (iOS 16.5.1, installed via TrollStore) whose only way past the alarm is photographing a randomly picked registered object, which then keeps ringing for a configurable 10 minutes, and which a sleepy owner can't disable, edit, or uninstall.

**Architecture:** All decision logic (scheduling, edit lock, ring state machine, backup-notification planning, tone synthesis, photo matching) lives in a local Swift package `AlarmyCore` with no UIKit dependency, so it is unit-tested with `swift test` on a GitHub Actions macOS runner. A thin SwiftUI app target (generated by XcodeGen) wires that logic to AVAudioEngine (keep-alive + alarm tone), UserNotifications (critical-alert backups), AVFoundation camera, and Vision. CI builds unsigned, fake-signs with `ldid` + entitlements, and publishes `Alarmy.tipa` as a GitHub Release that the owner opens in TrollStore.

**Tech Stack:** Swift 5.9+, SwiftUI, AVFoundation, UserNotifications, Vision, MediaPlayer, FamilyControls/ManagedSettings (optional), XcodeGen, ldid, GitHub Actions (`macos-15`), `gh` CLI.

**Spec:** `docs/superpowers/specs/2026-10-21-alarmy-design.md`

## Global Constraints

- Deployment target **iOS 16.0**. Target device: iPhone 13 Pro Max, **iOS 16.5.1 (c)**, TrollStore. No AlarmKit, no SwiftData, no `@Observable` (all iOS 17+). Use `ObservableObject`.
- Swift + SwiftUI only. **No third-party Swift packages.**
- Bundle ID `com.inverspe.alarmy`, display name `Alarmy`.
- Defaults (per alarm): `ringAfterMinutes = 10` (range 1–60), `lockHours = 8` (0–12), `earlyClearMinutes = 30` (0–60, 0 = off). Global: `strictness = .medium`.
- `missesBeforeSwitch = 5`. Hard cap: an occurrence is "active" for at most **2 hours** after its fire time.
- An alarm can't be enabled with zero registered objects. Onboarding asks for at least 3.
- **No snooze, skip, stop, or dismiss control anywhere while ringing or counting down.**
- Camera capture only. Never the photo library.
- Repo: **public** `github.com/inverspe/alarmy`. Work on branch `dev`. Every push builds and publishes a prerelease `build-<run_number>` with asset `Alarmy.tipa`. No personal data (photos, settings) is ever committed.
- Commands run from the owner's Windows PC in Git Bash. Nothing iOS builds locally, so "run the tests" always means **push and watch CI** (`gh run watch <id> --exit-status`).
- Skills: the owner pre-approved **frontend-design** for designing the screens. Ask the owner before invoking any other skill.

## Review Focus

1. **The app wasn't running at fire time** (killed overnight, phone rebooted) and the owner taps a backup notification 10 minutes late. It must open straight into the mission for that occurrence, and must not after 2 h or after completion. *Test: Task 4 `testActiveOccurrence*`.*
2. **Two alarms fire during one session** (6:30 and 6:35). The owner should do one mission and one countdown, and both occurrences count as done. *Test: Task 4 `testMarkFinishedCoversOverlappingAlarms`.*
3. **No usable object at fire time** (all photos failed to load). The alarm must not ring forever. It rings for the full countdown and then stops. *Test: Task 6 `testStartWithNoObjectsGoesStraightToCountdown`.*
4. **DST or travel.** A 6:30 alarm stays 6:30 local wall time across a DST change and in whatever time zone the calendar is set to. *Test: Task 4 `testDSTSpringForward`, `testUsesCalendarTimeZone`.*
5. **The owner moves the iPhone clock forward by hand** to lift the edit lock or skip the countdown. The trusted clock ignores it until a reboot. *Test: Task 5 `testClockMovedForwardIsIgnored`.*

### Task 5: Trusted clock, edit lock, early-clear window

**Files:**
- Create (replacing the Task 3 `ClockAnchor` placeholder): `Sources/AlarmyCore/TrustedClock.swift`, `Sources/AlarmyCore/EditLock.swift`, `Tests/.../TrustedClockTests.swift`, `Tests/.../EditLockTests.swift`

**Interfaces:**
- Consumes: `Schedule`, `Occurrence`, `OccurrenceKey`.
- Produces:
  - `public struct ClockAnchor: Codable, Equatable { wall: Date; monotonic: TimeInterval }`
  - `public enum TrustedClock`
    - `static let tolerance: TimeInterval = 120`
    - `static func now(wall: Date, monotonic: TimeInterval, anchor: ClockAnchor?) -> Date`
    - `static func refreshedAnchor(_ anchor: ClockAnchor?, wall: Date, monotonic: TimeInterval) -> ClockAnchor`
    - App side: `monotonic` = `Double(clock_gettime_nsec_np(CLOCK_MONOTONIC)) / 1e9`. On Darwin this counts time spent asleep, and it resets on reboot.
  - `public enum EditLock`
    - `static func lockedUntilDone(_ alarms: [Alarm], completed: [OccurrenceKey: Date], sessionActive: Bool, now: Date, calendar: Calendar) -> Occurrence?`. Returns the occurrence currently holding the lock, or nil if unlocked. `AppModel` passes `sessionActive = state.ringSession.map { $0.phase != .finished } ?? false`.
    - `static func earlyClearable(_ alarms: [Alarm], completed: [OccurrenceKey: Date], now: Date, calendar: Calendar) -> Occurrence?`

- [ ] **Step 1: Write failing tests.** `TrustedClock` algorithm:
  - With no anchor, or `monotonic < anchor.monotonic` (a reboot), return `wall`.
  - Otherwise `derived = anchor.wall + (monotonic − anchor.monotonic)`. Return `wall` if `|wall − derived| ≤ tolerance`, else `derived`.
  - `refreshedAnchor` returns a fresh `(wall, monotonic)` only when `now` would have returned `wall`. Otherwise it keeps the old anchor.

```swift
let T = date("2026-10-20 23:00"); let A = ClockAnchor(wall: T, monotonic: 1000)
func testConsistentClock()        { XCTAssertEqual(TrustedClock.now(wall: T + 600, monotonic: 1600, anchor: A), T + 600) }
func testSmallDriftTrustsWall()   { XCTAssertEqual(TrustedClock.now(wall: T + 650, monotonic: 1600, anchor: A), T + 650) }
func testClockMovedForwardIsIgnored() { XCTAssertEqual(TrustedClock.now(wall: T + 600 + 3600*8, monotonic: 1600, anchor: A), T + 600) }
func testClockMovedBackIsIgnored()    { XCTAssertEqual(TrustedClock.now(wall: T - 3600, monotonic: 1600, anchor: A), T + 600) }
func testRebootTrustsWall()       { XCTAssertEqual(TrustedClock.now(wall: T + 99, monotonic: 5, anchor: A), T + 99) }
```
